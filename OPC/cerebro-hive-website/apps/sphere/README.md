# CerebroSphere — Unified AEOS Dashboard

> **CerebroHive AEOS · Month 1 · Claude-primary product · The product every prospect demos first.**

CerebroSphere is the top-level command dashboard that unifies all 50 AEOS products into a single real-time pane of glass. Role-based views auto-tailored by Claude, live agent fleet monitoring, product health grid, unified alerts, and an intelligent onboarding wizard.

## Routes

| Route | Description |
|-------|-------------|
| `/dashboard` | Unified overview — Claude narrative, platform KPIs, product health, alerts, FinOps |
| `/dashboard/agents` | Live agent fleet grid — status, success rate, executions, latency |
| `/dashboard/products` | All 50 AEOS products health grid, grouped by platform layer |
| `/dashboard/alerts` | Unified alert feed from all AEOS products (Alert + Incident tables) |
| `/onboarding` | 3-step tenant onboarding wizard — Claude generates intelligent defaults |

## Architecture

```
apps/sphere/
  app/
    api/
      dashboard/route.ts          ← GET aggregated platform data (Redis 20s)
      narrative/route.ts          ← POST Claude role-tailored NL briefing (Redis 5min)
      onboard/route.ts            ← POST create Tenant + Workspace + Claude defaults
      stream/platform/route.ts    ← SSE live platform updates every 20s
    dashboard/
      page.tsx                    ← Unified overview (CEO/CTO/COO/Dept views)
      agents/page.tsx             ← Agent fleet grid
      products/page.tsx           ← 50-product health grid by layer
      alerts/page.tsx             ← Unified alert feed
    onboarding/page.tsx           ← 3-step wizard
  shared/
    lib/
      types.ts                    ← All TypeScript types
      db.ts                       ← Prisma singleton
      redis.ts                    ← ioredis singleton + cacheGet/cacheSet
      claude-client.ts            ← Anthropic SDK — generateRoleNarrative, generateOnboardingDefaults
      role-config.ts              ← Role panel mapping and Claude audience instructions
      aggregator.ts               ← Parallel Prisma sweep → DashboardData
    ui/
      AppShell.tsx                ← Sidebar, role switcher, header, QueryClientProvider
      SphereCard.tsx              ← SphereCard, StatusDot, SeverityBadge, MetricTile, ProgressBar, AIBadge
      globals.css                 ← Design tokens (CSS custom properties)
```

## Role-based intelligence

| Role | What Claude focuses on |
|------|----------------------|
| CEO | Revenue, enterprise risk, growth metrics, board-level narrative |
| CTO | System reliability, agent performance, security posture, infrastructure |
| COO | Workflow throughput, SLAs, operational efficiency, team output |
| Dept Head | Team KPIs, budget, relevant workflows and alerts for their function |

All narratives are generated by `claude-sonnet-4-6` from live platform data, cached per role for 5 minutes.

## Data sources

| Source | Models / Endpoints |
|--------|-------------------|
| Prisma `@cerebro/db` | Agent, AgentExecution, Alert, Incident, Metric, HealthCheck, Workflow, WorkflowExecution, AIUsageRecord, Tenant, Workspace |
| Anthropic Claude | `claude-sonnet-4-6` — role narrative, onboarding defaults |
| Redis `ioredis` | 20s dashboard cache, 5min per-role narrative cache |
| Platform-API | Proxied via `/proxy/platform/*` |
