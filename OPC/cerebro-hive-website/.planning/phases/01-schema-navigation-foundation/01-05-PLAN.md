<objective>
Tear out the fabricated UI on the 10 CerebroForge tools that have no backend controller, and replace each page body with the single shared `PlaceholderModule`.

Purpose: CONTEXT.md D-15 is explicit — these pages are not blank stubs, they render fabricated statistics, fake generated-artifact lists, and buttons wired to `setTimeout` instead of any API call. FORGE-02 and the project's core value ("never a fake number, a dead link, or a blank stub") require active removal, not a placeholder layered on top. D-03 forbids building new forge-api surface for these tools in this phase.
Output: 10 pages, each a single `PlaceholderModule` render with the exact nav-registry title.
</objective>

<phase_goal>
**As a** CerebroHive Studio user, **I want to** click any destination in the sidebar and land on either a working page or a clearly-labelled "not yet available" page, **so that** I never hit a 404, a dead link, or fabricated data while navigating the product.

This plan owns the "never fabricated data" half for CerebroForge's 10 unbacked tools.
</phase_goal>
