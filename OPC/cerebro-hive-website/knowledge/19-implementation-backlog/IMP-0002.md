# IMP-0002: MCP Server Implementation in tool-gateway

```yaml
id: "IMP-0002"
title: "MCP Server Protocol Implementation in services/tool-gateway"
source_knowledge:
  - "KN-INFRA-000001"   # Model Context Protocol

problem: >
  services/tool-gateway uses a proprietary tool registration and invocation protocol.
  As MCP (Model Context Protocol) becomes the industry standard for connecting LLMs
  to tools and data, Cerebro Nexarch's tool ecosystem risks becoming an isolated
  proprietary island. External tools that publish MCP servers cannot be consumed without
  custom adapter code. Cerebro tools cannot be accessed by MCP-native clients.

proposed_solution: >
  Implement MCP server protocol in services/tool-gateway using the official MCP SDK
  (github.com/modelcontextprotocol/sdk). This exposes the existing Cerebro tool
  registry as a standards-compliant MCP server.
  
  Phase 1 (MCP Server): tool-gateway responds to MCP client connections,
  exposing registered tools as MCP Tool capabilities with JSON Schema descriptors.
  Transport: HTTP/SSE (fits existing REST + streaming architecture).
  
  Phase 2 (MCP Client): packages/agent-sdk includes MCP client to consume external
  MCP servers (GitHub, Slack, PostgreSQL, custom enterprise MCP servers).
  Replaces proprietary connector adapters one by one.

business_value: >
  Connects Cerebro Nexarch to the growing MCP ecosystem (1000+ community servers).
  Enables enterprise customers who already use MCP-native tools to plug them into
  CerebroAgent without custom integration work. Reduces Cerebro engineering cost:
  no longer need to build and maintain proprietary adapters for each data source.

technical_value: >
  Replaces N custom adapter implementations with one protocol implementation.
  The MCP standard handles capability negotiation, tool schema validation, and
  error reporting — reducing tool-gateway complexity. JSON Schema tool descriptors
  improve agent tool selection (LLMs can better understand tool capabilities from
  structured schemas than from ad-hoc descriptions).

affected_components:
  - "services/tool-gateway"
  - "packages/agent-sdk"

dependencies:
  - "@modelcontextprotocol/sdk npm package"
  - "Existing tool registration API in tool-gateway"
  - "HiveShield authorization policy (MCP tool invocations must be authorized)"

security_implications: >
  MCP tool descriptions from external servers are UNTRUSTED per the MCP spec.
  Implementation must:
  1. Never execute tools from unverified MCP servers without explicit allowlist
  2. Validate all tool input/output against JSON Schema before passing to agent
  3. Route all tool invocations through HiveShield authorization (no bypass)
  4. Treat MCP server tool descriptions as D-grade evidence for authorization decisions
  5. Implement timeout on all MCP tool calls (prevent hung connections)
  
  Prompt injection risk: MCP Resources can return content that manipulates agent.
  Implement content sanitization on Resource responses before adding to agent context.

estimated_complexity: MEDIUM
priority: P1

acceptance_criteria:
  - "GET /mcp/initialize returns MCP capability response per spec 2025-11-25"
  - "Claude Desktop can connect to tool-gateway as MCP server and invoke a Cerebro tool"
  - "All MCP tool invocations logged with tool_id, agent_id, tenant_id, timestamp"
  - "HiveShield policy enforced: unauthorized tool calls return MCP error, not silently allowed"
  - "JSON Schema validation on all tool inputs; malformed inputs rejected"
  - "agent-sdk MCP client can connect to GitHub MCP server and list repositories"
  - "External MCP server responses are sanitized before inclusion in agent context"

tests_required:
  - "Unit: MCP initialize/shutdown handshake"
  - "Unit: tool registry → MCP Tool capability translation"
  - "Integration: Claude Desktop → tool-gateway MCP server → tool execution"
  - "Integration: agent-sdk MCP client → external GitHub MCP server"
  - "Security: unauthenticated MCP connection rejected"
  - "Security: malformed tool input (JSON Schema violation) rejected"
  - "Security: prompt injection in MCP Resource response detected and logged"

status: BACKLOG
```
