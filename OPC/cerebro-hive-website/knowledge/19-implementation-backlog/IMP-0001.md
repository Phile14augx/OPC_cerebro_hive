# IMP-0001: Agent Subscription Registry — Event-Driven Agent Wake-Up

```yaml
id: "IMP-0001"
title: "Agent Subscription Registry — Event-Driven Agent Wake-Up for swarm-runtime"
source_knowledge:
  - "KN-AGENT-000002"   # Event-Driven Agent Trigger Architecture
  - "KN-AGENT-000001"   # Conway — motivating example

problem: >
  Cerebro Nexarch agents currently require explicit dispatch — a user or orchestrator
  must initiate each agent invocation. There is no mechanism for agents to register
  interest in external events (webhooks, scheduled timers, GitHub events) and
  wake up autonomously when those events fire. This limits CerebroAgent to reactive
  (prompt-response) use cases and prevents the ambient / always-on agent patterns
  that Conway and the broader industry are moving toward.

proposed_solution: >
  Implement an Agent Subscription Registry in services/swarm-runtime that allows
  registered agents to subscribe to event sources. When a subscribed event arrives,
  the registry routes it to the appropriate agent instance for processing.
  
  Implementation leverages existing stack:
  - NATS JetStream: event routing substrate (already deployed)
  - Temporal.io: agent instance lifecycle and state persistence (already deployed)
  - PostgreSQL: subscription registry storage (already deployed)
  
  New components required:
  1. Subscription table in PostgreSQL: (id, agent_id, tenant_id, event_topic, filter_expr, enabled)
  2. NATS consumer in swarm-runtime: routes incoming events to subscribed agents
  3. Webhook ingress endpoint in tool-gateway: POST /v1/hooks/{hook_id} → NATS publish
  4. Temporal.io cron workflow type: fires NATS event on schedule
  5. agent-sdk subscription API: agent.subscribe(source, filter, handler)

business_value: >
  Enables CerebroAgent to operate as ambient enterprise intelligence — monitoring
  systems, reacting to events, and taking action without continuous user engagement.
  This is the foundational pattern for enterprise workflow automation products.
  Directly required for "Digital Twin Sensor Monitor" and "Code Review Agent" use cases.

technical_value: >
  Leverages existing NATS JetStream and Temporal.io investments. Unlocks event-driven
  agent composition (agents subscribing to other agents' output events).
  Reduces agent operational cost: compute only when events arrive.

affected_components:
  - "services/swarm-runtime"
  - "packages/agent-sdk"
  - "services/tool-gateway"
  - "services/governance-api"   # subscription approval workflow

dependencies:
  - "NATS JetStream operational (already deployed)"
  - "Temporal.io operational (already deployed)"
  - "PostgreSQL with Prisma (already deployed)"
  - "IMP-0003: Per-Agent Tool Authorization (security dependency)"

security_implications: >
  External webhooks are unauthenticated ingress. tool-gateway must:
  1. Generate HMAC webhook secrets per subscription; validate signature on every request
  2. Rate-limit events per subscription to prevent cost amplification attacks
  3. Require explicit tenant admin approval for external webhook subscriptions
  4. Log all event firings in immutable audit log (existing P0 requirement)
  
  Agent actions triggered by events must pass through HiveShield authorization
  policy before any tool invocation — no bypass for event-triggered paths.

estimated_complexity: MEDIUM
priority: P1

acceptance_criteria:
  - "Agent can register a subscription: agent.subscribe({ source: 'webhook', filter: { topic: 'github.pr.opened' } })"
  - "POST to /v1/hooks/{hook_id} fires within 5 seconds to registered agent"
  - "Scheduled subscription fires within 60 seconds of configured cron time"
  - "Agent state is persisted across event firings (prior event context available)"
  - "Webhook signature validation rejects unsigned/tampered requests"
  - "Rate limit enforced: max 10 events/minute per subscription (configurable)"
  - "Subscription CRUD operations require tenant admin authorization"
  - "All event firings logged in governance-api audit trail"

tests_required:
  - "Unit: subscription registry CRUD"
  - "Unit: NATS routing to correct agent instance"
  - "Integration: webhook ingress → NATS → agent execution → audit log"
  - "Integration: Temporal.io cron → event → agent"
  - "Security: unsigned webhook rejected; rate limit enforced"
  - "Load: 100 concurrent webhook events, all routed correctly within 5s"

status: BACKLOG
```
