  - "KN-INFRA-000002"    # Reasoning Model Routing — CEREBRO_RECOMMENDATION to validate

hypothesis: >
  Routing PLANNING-type agent tasks (multi-step decomposition, complex reasoning) to
  DeepSeek-R1 instead of GPT-4o will reduce LLM cost for those tasks by ≥50% while
  achieving quality parity (≤5% regression on a standardized planning task evaluation suite).
  For data-sovereign tenants routed to o3-mini instead of GPT-4o, cost reduction is
  estimated ≥30%. EXP-0002 validates these estimates against actual Cerebro agent workloads.

success_criteria:
  - "DeepSeek-R1 vs GPT-4o on PLANNING tasks: cost reduction ≥50%, quality regression ≤5%"
  - "o3-mini vs GPT-4o on PLANNING tasks: cost reduction ≥30%, quality regression ≤5%"
  - "Routing classifier accuracy ≥85%: correctly identifies PLANNING vs non-PLANNING tasks"
  - "DeepSeek-R1 latency overhead: ≤3× GPT-4o latency (acceptable for async planning)"
  - "No quality regression on non-PLANNING tasks (confirm GENERATION/CLASSIFICATION tasks unaffected)"

failure_criteria:
  - "Quality regression >10% on PLANNING tasks for either reasoning model"
  - "Routing classifier accuracy <70% (misroutes too many tasks)"
  - "DeepSeek-R1 latency >10× GPT-4o (unacceptable even for async tasks)"
  - "Thinking token budget causes runaway cost (output tokens >5× input tokens per call)"

  50 PLANNING tasks representing real CerebroAgent workloads:
  - 15 multi-step workflow decomposition tasks
  - 15 code architecture planning tasks  
  - 10 analysis + recommendation tasks
  - 10 debugging and root-cause analysis tasks

  (1) Task completion rate (did the agent complete the task?)
  (2) Output quality score (human evaluation + LLM-as-judge on 5-point scale)
  (3) Token cost (input + output tokens × model price)
  (4) Latency (time-to-first-token; total completion time)
  
  Baseline: all 50 tasks run with GPT-4o (current default).
  Experimental: same 50 tasks run with DeepSeek-R1 and o3-mini.

  A. Baseline: GPT-4o on all 50 tasks

  Data sovereignty note: EXP-0002 runs on synthetic/anonymized task content only.
