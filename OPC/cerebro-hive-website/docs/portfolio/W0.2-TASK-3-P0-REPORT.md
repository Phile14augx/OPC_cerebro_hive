## Task 3A — No-op typecheck

- `apps/platform-api` now runs `tsc -p tsconfig.json --noEmit`.
- `services/forge-api` now runs `tsc -p tsconfig.json --noEmit`.
- Both contracts passed against the real packages.
- A deliberate TypeScript assignment violation made each contract fail with
  `TS2322` before the fixture was removed.

## Task 3B — False-green tests

- Thirty workspaces now run real Vitest or Jest suites without
  `--passWithNoTests`.
- `services/forge-api` also removed `--passWithNoTests` from `test:break`; its
  two break suites passed with 74 active tests and 18 intentional skips.
- `packages/tokens` validates that every semantic/component token reference
  resolves to a declared token.
- `packages/tables` and `packages/visualization` are empty `export {}` shells,
  so their misleading test scripts were removed and their test contracts are
  explicitly `NOT-APPLICABLE` until behavior is introduced.
- `services/archive-worker` has no qualifying source in this baseline, so its
  misleading test script was removed and its test contract is explicitly
  `NOT-APPLICABLE` with source introduction as the review trigger.

## Task 3C — Prisma schema validation

- `packages/db` declares `validate:schema: prisma validate`.
- The canonical `packages/db/prisma/schema.prisma` passes.
- A persistent negative fixture injects an invalid Prisma field type and proves
  the same package-local validator returns non-zero.
- The fixture also checks that the package script exists, preventing pnpm's
  successful missing-script behavior from becoming another false green.
