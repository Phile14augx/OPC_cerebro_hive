# Archive

Documentation kept for historical reference — nothing here should be treated as current. Nothing is deleted from this repository's documentation without being clearly a byte-for-byte duplicate or generated garbage; anything else that's no longer current lands here instead.

| Folder | Contents |
|---|---|
| [`superseded/`](./superseded/) | Documents explicitly replaced by a newer version of the same document (each carries an `> Status: Archived` header pointing to its replacement) |
| [`historical/`](./historical/) | Dated snapshots, retired checklists, and early concept documents that were never formally "superseded" but are no longer the current picture — kept as record of how the project got here |

There is no `abandoned/` folder yet because no fully abandoned initiative was found during the August 2026 documentation reorganization — add one if that changes.
