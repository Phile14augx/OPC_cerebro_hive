# Intelligent Document Processing (IDP)

## Overview
CerebroHive's Intelligent Document Processing (IDP) service deploys autonomous pipelines to extract, classify, validate, and route data from unstructured and semi-structured documents (invoices, contracts, KYC forms).

Powered by **Gemini (Vision & Multimodal Extraction)** and **Codex (Data Pipeline & Routing Automation)**, this service replaces legacy OCR templates with dynamic, resilient AI processing.

## Key Elements
- **Multimodal Ingestion:** Handles PDFs, scanned images, handwritten notes, and mixed-media documents.
- **Dynamic Extraction Schemas:** Zero-template extraction using LLM reasoning.
- **Confidence Quality Gates:** Automated routing for human-in-the-loop (HITL) only when confidence falls below the defined threshold.
- **Safe Fallback Routing:** Deterministic validation of extracted payloads against business rules.
- **Continuous Learning:** The IDP Specialist agent analyzes edge cases to improve prompt instructions and OCR pre-processing.
