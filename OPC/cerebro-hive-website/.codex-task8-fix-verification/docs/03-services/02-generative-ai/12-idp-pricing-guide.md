# Pricing Guide: IDP Service

The Intelligent Document Processing (IDP) service operates on a fixed-fee model based on the complexity of the document taxonomy and the integration requirements.

## 1. Core Packages

### Standard IDP Pipeline ($40,000)
- **Scope:** 1-2 document types (e.g., standard invoices and purchase orders).
- **Extraction:** Up to 20 fields per document.
- **Integration:** Webhook / basic REST API payload delivery.
- **Timeline:** 4 weeks.

### Advanced IDP Pipeline ($85,000)
- **Scope:** 3-5 document types, including unstructured text (e.g., contracts, KYC forms).
- **Extraction:** Up to 50 fields, including nested tables and line items.
- **Integration:** Direct ERP/CRM integration (e.g., Salesforce, SAP) with safe fallback routing.
- **Timeline:** 6 weeks.

### Enterprise IDP Hub ($150,000)
- **Scope:** Multi-department document processing (Accounts Payable, Legal, HR).
- **Extraction:** Unlimited fields, cross-document reconciliation (e.g., three-way matching).
- **Integration:** Full enterprise service bus (ESB) integration, custom HITL UI portal.
- **Timeline:** 8-10 weeks.

## 2. Operating Costs (Run Phase)
- **Token Usage:** Billed monthly based on Gemini API usage.
- **Infrastructure:** $2,000/month for HiveRuntime and HiveOps monitoring.
