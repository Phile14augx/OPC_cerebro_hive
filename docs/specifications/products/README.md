# Product Specifications

50 files, one per product, named `<product>_spec.md`: 18 `cerebro*` products (the applied/business-application layer — CRM, ERP, Finance, HR, etc.) and 32 `hive*` products (the underlying platform/infrastructure layer — Compute, Storage, Identity, Agents, etc.).

For the full registry with lifecycle status (GA / Beta / Early Access / Coming Soon / Labs) and links, see [`../../architecture/product-registry.md`](../../architecture/product-registry.md) — that is the canonical index; this folder holds the specs it links to.
