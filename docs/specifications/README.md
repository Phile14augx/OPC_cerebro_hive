# Specifications

Detailed specs for what a product or feature does — as opposed to `../architecture/`, which covers how the platform as a whole is built.

| Folder | Contents |
|---|---|
| [`products/`](./products/) | One `*_spec.md` per product across the Cerebro and Hive product families (50+ files) |
| [`features/`](./features/) | Design specs for individual feature slices (paired with an implementation plan of the same date under [`../plans/`](../plans/README.md)) |

## What doesn't belong here

- The service catalog and marketing-facing service descriptions → the numbered content catalog at `../03-services/` and related top-level `docs/` folders
- Architecture decisions → `../architecture/decisions/`
