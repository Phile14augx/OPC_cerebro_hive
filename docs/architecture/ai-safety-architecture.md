# CerebroHive AI Safety Reference Architecture (Layer 6)

## Overview
AI Safety is Layer 6 of the EIOS stack. It provides the necessary guardrails, compliance, and governance mechanisms to safely deploy AI in the enterprise.

## Core Capabilities
- **Prompt Firewalls:** Prevent prompt injection and adversarial attacks.
- **PII Detection:** Automatically redact or anonymize sensitive data before it reaches Layer 2 (Models).
- **Policy Engine:** Enforce RBAC/ABAC and domain-specific rules on agent actions.
- **Model Sandboxing:** Ensure untrusted code generated by AI is executed in isolated environments.

## Dependency Rules
- Layer 6 wraps traffic between Layer 7 (AI Engineering/LLMOps) and Layer 3 (Agent Runtime).
- Nothing above Layer 6 may bypass it when communicating with external LLMs or internal enterprise data.
