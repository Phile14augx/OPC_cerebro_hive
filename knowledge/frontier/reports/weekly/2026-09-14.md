## Executive signal

The strongest new signal is not another agent framework. Independent security research, two concrete agent-runtime vulnerabilities, and new trajectory datasets converge on one requirement: agent configuration, identity, authorization, sandboxing, provenance, and effect monitoring must be enforced outside the model. Prompt filtering alone cannot stop pre-model configuration execution, mutable MCP dependencies, ambient shell authority, or delayed hijacking.

Three experiment-quality opportunities emerged: step-level injection evaluation, dependency-aware long-horizon evaluation, and multimodal-native document retrieval. None may start now. Wave 0 still sequences durable persistence before the canonical agent runtime, KRN-015 remains frozen until Wave 1 after W0.3, and no frontier experiment has an open WIP slot.

Provider releases reinforce the existing model-gateway strategy. GPT-6 Astra, Claude Fable 5.1, Gemini 3.8 Flash, and Muse Glimmer must enter through the model registry and qualification suite; none justifies direct product binding. The OpenAI Agents API is an adapter candidate only, not a replacement for the canonical runtime.

## Competitive and convergence assessment

OpenAI’s managed harness increases time-to-market pressure but also increases runtime lock-in; Nexarch should integrate only through a replaceable AgentPort adapter. Anthropic and Google’s rapid low-cost/agentic model releases reduce durable differentiation at the model layer, strengthening the value of provider-neutral routing, governance, evaluation, and customer-specific knowledge. Meta’s commercially usable local agent model creates a privacy/cost option but does not remove the need for the same external policy and sandbox plane.

Convergence strength is **high** for externally enforced agent execution envelopes: empirical harness scanning, concrete Flowise/Gemini vulnerabilities, step-level attack data, and vendors’ own disclosed approval/injection limitations all point in the same direction.
