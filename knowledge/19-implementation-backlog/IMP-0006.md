## Problem Statement

Cerebro Nexarch currently operates as a closed agent ecosystem — CerebroAgents can only call tools defined within the Cerebro stack. This creates two limitations:

1. **Inbound:** External enterprise agents (SAP, Salesforce, ServiceNow) cannot delegate tasks to CerebroAgents, even where Cerebro has specialized AI capabilities (data analysis, code generation, knowledge graph search).

2. **Outbound:** CerebroAgents cannot delegate to specialist external agents (e.g., a Salesforce CRM agent for customer data, a ServiceNow agent for IT ticketing) and must instead use brittle REST API integrations.

A2A (Agent-to-Agent Protocol, Google 2025-04-09) provides a standardized HTTP + SSE + JSON-RPC 2.0 protocol for agent federation, adopted by 50+ enterprise partners at launch. Implementing A2A turns `services/swarm-runtime` into a federated multi-agent hub.

---

## Solution Architecture

A2A integration has two independent layers, each independently deployable:

### Layer 1 — A2A Server: Expose CerebroAgents to External Callers (Weeks 1–2)

External systems (Salesforce Agent, SAP AI Core, etc.) discover and invoke CerebroAgents via A2A.

**A2A Server endpoints** (new routes on `services/swarm-runtime`):

```typescript
// A2A task lifecycle — JSON-RPC 2.0 over HTTP
POST /a2a/v1
// Methods:
//   tasks/send         — submit a new task
//   tasks/sendSubscribe — submit + subscribe to SSE stream
//   tasks/get          — get task status
//   tasks/cancel       — cancel in-progress task
//   tasks/resubscribe  — reconnect to existing SSE stream

// A2A SSE stream
GET /a2a/v1/events/{task_id}

// Agent discovery
GET /.well-known/agent.json

// Implementation:
import { createA2AServer } from '@cerebro/a2a-sdk'

const a2aServer = createA2AServer({
  agentCard: CEREBRO_AGENT_CARD,
  taskHandler: async (task: A2ATask, context: A2AServerContext) => {
    // 1. Validate caller credentials + rate limits
    const caller = await auth.validateA2AToken(context.bearerToken)
    
    // 2. Map A2A task to CerebroAgent invocation
    const agentTask = mapA2ATaskToCerebroTask(task, caller.tenantId)
    
    // 3. Invoke via swarm-runtime (same path as internal tasks)
    const execution = await swarmRuntime.execute(agentTask)
    
    // 4. Stream progress via SSE
    for await (const update of execution.stream()) {
      yield { status: update.status, artifact: update.artifact }
    }
  }
})
```

**Task state machine** (A2A spec):
```
submitted → working → (completed | failed | cancelled)
                    ↘ input-required (if agent needs clarification)
```

All A2A task state transitions are logged to `governance-api` with the external caller's identity.

### Layer 2 — A2A Client: Delegate Tasks to External Agents (Weeks 3–4)

CerebroAgents invoke external A2A-compatible agents for specialized tasks.

**External agent registry** (stored in `services/governance-api`):

```typescript
// Register an external A2A agent:
POST /v1/a2a/agents
{
  name: "Salesforce CRM Agent",
  agent_card_url: "https://salesforce.com/ai/.well-known/agent.json",
  trusted: true,                    // manually approved by platform admin
  allowed_skill_ids: ["crm-query"],  // limit which skills this agent can invoke
  tenant_whitelist: ["tenant-123"],  // only these tenants can delegate to it
  auth_secret_id: "salesforce-a2a-key",  // secret in packages/secrets-core
}

// Runtime: agent-sdk A2A client
const externalAgent = await a2aClient.getAgent('salesforce-crm')
const result = await externalAgent.sendTask({
  message: {
    role: 'user',
    parts: [{ type: 'text', text: 'Get the last 5 support tickets for account ABC-123' }]
  }
})
```

**Security: external agent task payloads are untrusted (IMP-0004 dependency)**

```typescript
// All results from external A2A agents are wrapped as untrusted content:
const wrappedResult = wrapContent(
  result.artifact.text,
  { type: 'tool_output', id: `a2a:${externalAgent.name}` },
  'untrusted'           // external A2A agent results = untrusted
)
```

**Routing policy for external delegation:**

```typescript
// packages/agent-sdk — ExternalDelegationPolicy
export async function shouldDelegate(task: CerebroTask): Promise<DelegationDecision> {
  // Only delegate if:
  // 1. The required capability is NOT available internally
  // 2. A trusted external agent is registered for this capability
  // 3. The data being shared is NOT sensitive (PII/PHI gate)
  // 4. Tenant has enabled external agent delegation (opt-in)
  
  const available = await internalCapabilities.canHandle(task)
  if (available) return { delegate: false, reason: 'INTERNAL_CAPABILITY_AVAILABLE' }
  
  const externalAgent = await registry.findAgent(task.requiredCapability, task.tenantId)
  if (!externalAgent) return { delegate: false, reason: 'NO_REGISTERED_AGENT' }
  
  const piiPresent = await piiDetector.scan(task.inputText)
  if (piiPresent && !task.tenant.allowPiiDelegation) {
    return { delegate: false, reason: 'PII_GATE_BLOCKED' }
  }
  
  return { delegate: true, agent: externalAgent }
}
```

## Acceptance Criteria

1. **Agent Card published** — `GET /.well-known/agent.json` returns valid A2A Agent Card JSON conforming to A2A spec v1.0. Verified by A2A compliance validator.

2. **Inbound task** — External caller POSTs a `tasks/send` JSON-RPC request; task is executed by a CerebroAgent; result returned in A2A `Artifact` format.

3. **SSE streaming** — External caller uses `tasks/sendSubscribe`; receives SSE events for `working` and `completed` state transitions within expected latency.

4. **Task cancellation** — External caller sends `tasks/cancel`; in-progress CerebroAgent execution is gracefully terminated; task state transitions to `cancelled`.

5. **Inbound authentication** — `tasks/send` without a valid bearer token returns HTTP 401. Verified by negative test.

6. **Outbound delegation** — CerebroAgent delegates task to a mock external A2A agent (test double); result is received, wrapped as untrusted, and injected into context.

7. **External result trust marking** — External A2A agent result content is wrapped with `trust="untrusted"` before entering CerebroAgent context. Verified by context snapshot assertion.

8. **Tenant isolation** — Agent from Tenant A cannot invoke external agents registered for Tenant B only. Verified by cross-tenant delegation attempt test.

9. **PII gate** — Task containing PII (test: "customer name is John Doe SSN 123-45-6789") is not delegated to external agent when tenant `allowPiiDelegation = false`.

10. **Audit log** — Every inbound A2A task and every outbound delegation produces a governance-api audit record with: task_id, caller/callee identity, tenant_id, skill_id, task_status, timestamp.

## Implementation Notes

- Use the official `@google/a2a` npm package if available; otherwise implement JSON-RPC 2.0 + SSE manually per the spec at `a2a-protocol.org`
- **Start with Layer 1 (inbound) only** — this provides immediate value (enterprise systems can invoke Cerebro) with lower risk (no external data brought in)
- Layer 2 (outbound) requires IMP-0004 (trust marking) to be complete first — no external agent results may enter agent context without trust wrapping
- Rate limiting: 100 inbound A2A tasks per minute per external caller (configurable); enforced at swarm-runtime ingress
- A2A task IDs are Cerebro execution IDs prefixed with `a2a_` for easy correlation in audit logs
